# MANDOROS — Free 16GB RAM Hugging Face Spaces Mirror

Welcome to the **16 GB RAM + 2 vCPU Hugging Face Space Mirror** of MANDOROS (Meta-Analysis Network for Data, Outcomes & Research Optimization Synthesis).

- **Primary Render Production Cloud**: [https://mandoros.onrender.com](https://mandoros.onrender.com)
- **High-Memory Mirror**: Hugging Face Spaces (Gradio SDK)

### Configuration Instructions:
1. Create a new Space on [Hugging Face Spaces](https://huggingface.co/new-space) with SDK `Gradio`.
2. Add your GitHub repository secret `HF_TOKEN` (Hugging Face write token) and `HF_SPACE_REPO` (e.g., `yourusername/mandoros-evidence`).
3. Every push to your GitHub repository automatically synchronizes with both Render and this 16GB RAM Space.
